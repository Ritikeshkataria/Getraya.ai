# GetRaya

GetRaya is an AI receptionist / AI employee SaaS concept for local businesses.

## Included in this build
- Marketing website: Home, Product, How It Works, industry solution pages, Channels, Pricing, Resources, About, Demo
- Client workspace dashboard
- GetRaya Control Center/admin dashboard
- Responsive UI system in black, white and lime
- Demo data and placeholder states for future production integrations

## Run locally
1. Install Node.js 20+
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

## Production integrations not enabled yet
- Meta WhatsApp Cloud API
- OpenAI production agent calls
- Supabase/PostgreSQL persistence
- Payments/billing provider
- Real authentication
- Voice/Instagram/Email channels

The UI and route architecture are intentionally prepared for these integrations.
